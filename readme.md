# EV Purchase Prediction

Kaggle binary classification project predicting whether a customer will buy an electric vehicle.

**Competition:** [Kaggle Playground Series S6E9](https://www.kaggle.com/competitions/playground-series-s6e9)

## Methods

* **CatBoost**
* **XGBoost**
* Feature Engineering
* Hyperparameter Tuning
* Cross-Validation
* Ensemble

## Data

* `train.csv` — training data
* `test.csv` — test data for prediction
* `sample_submission.csv` — submission format

## Goal

Optimize CatBoost and XGBoost models and combine their predictions for the best possible Kaggle ranking.
